# Security

Please don't report a security problem in a public issue. Use **Report a vulnerability** on the
[Security tab](https://github.com/VividNightmareUnleashed/vrcx-android/security/advisories/new) instead, so it stays
private until a fix is out.

Say what you found, how to reproduce it, and which version of the app or the Windows companion it affects.

Fixes go into the latest release. The 1.x app on the `legacy` branch is no longer updated.

A problem in the VRCX frontend that desktop VRCX has as well belongs with the
[VRCX project](https://github.com/vrcx-team/VRCX).
